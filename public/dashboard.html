📘 Lên live từ PC (TikTok LIVE Studio hoặc OBS)

  1. Bấm đúp BAT-LIVE.bat → cửa sổ đen hiện “CHỦ THẦU TÍ HON đang chạy” (đừng tắt cửa sổ này).
  2. TikTok LIVE Studio: đặt khung dọc → Thêm nguồn Link/Trang web → dán link bên phải, kích thước 1080×1920 (muốn chữ nét hơn: 1620×2880 rồi thu nhỏ vừa khung).
  3. Bật “điều khiển âm thanh qua LIVE Studio/OBS” để giọng MC lên live.
  4. Bấm Phát trực tiếp → quay lại đây tab Kết nối TikTok → Kết nối.
  5. Mở trang này trên điện thoại (cùng Wi‑Fi): http://IP-máy-tính:3010 để điều khiển khi đang live.
